How to build 1a in ERPNext v16 everything except step 6 is config, not code
01 Turn FPS into a parent workspace Sidebar → Create Workspace, once per category (Sales, Operations, Accounts, HR, Reports, Masters & Setup). In each one set Parent = FPS and give it a sequence so the order sticks. Keep the existing FPS page as the parent and rename its title to FPS Home. For HR, don't rebuild anything — link to the stock HR doctypes (Employee, Attendance, Leave Application, Shift Assignment, Expense Claim, Payroll Entry, Salary Slip) so ERPNext's own permissions and reports keep working.
02 Shortcuts with live counts Edit mode → Add Shortcut. Set Type = DocType, Color from the fixed palette, and fill Statistics Filter — that is what draws the count badge (e.g. Customs Tracker with {"status":"Submitted"}). Set DocView = List so it opens filtered.
03 The four number cards New Number Card per KPI: document type, function Count or Sum, filters, colour, and Is Public on. “Delivered, not invoiced” and “GP this month” can't be expressed as plain filters — make those two Report-type number cards pointing at a query report, or add a billing_status / gross_profit field on Job Order kept current by a hook.
04 Quick lists and charts Add Quick List → Job Order, filter status not in Delivered/Cancelled, sort by deadline. Charts are Dashboard Chart records: Monthly GP Trend as a Sum / bar with time interval Monthly, Open Jobs by SOW as a Group By / donut on the SOW field. Add both to the page with Add Chart.
05 List view indicators Add fps_erpnext/fps/doctype/job_order/job_order_list.js exporting frappe.listview_settings["Job Order"] with add_fields, get_indicator returning [label, colour, filter], and formatters for the margin column. Five colours only: red late/blocked, orange at customs, blue in transit, purple unbilled, green closed — same meanings on every FPS doctype.
06 The pipeline strip — the only custom code Create a Custom HTML Block, paste the strip markup, and in its script call one @frappe.whitelist() method in fps_erpnext/api/ that returns the seven stage counts in a single grouped query. Each tile links to /app/job-order?status=…. Skip this block entirely and you have 1b.
07 Get it out of the browser and into the app Workspaces, number cards, charts and custom blocks built in the UI live in your site database, not in fps_erpnext. Build them on a staging site, then export — bench --site <site> export-fixtures with the Workspace / Number Card / Dashboard Chart doctypes listed in fixtures in hooks.py — so the layout ships with the app, survives a fresh install, and is reviewable in git. Roles matter too: point each category workspace at the roles that use it, so an accounts user never sees the Operations tree.
